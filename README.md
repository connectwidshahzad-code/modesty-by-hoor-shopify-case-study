## My contribution

- Custom homepage sections, including a responsive hero slider and benefits bar.
- Custom product detail section with image gallery, variants, quantity and purchase actions.
- Shopify product recommendations presented through responsive product cards.
- Mobile gallery, purchase controls, typography and spacing refinements.

## Technologies and tools

Shopify · Liquid · HTML · CSS · JavaScript · Shopify Theme Editor

Wishlist saved-state and account synchronization were outside the documented verification. Commercial performance was not measured in this case study.
